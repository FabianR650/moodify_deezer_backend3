# Moodify (Deezer Version) 🎵  
A lightweight mood‑based music search API powered by the free Deezer public API.  
No OAuth, no tokens, no Premium requirement — just fast, clean results.

---

## 🚀 Features
- Mood → genre mapping (happy, sad, relaxed, energetic, etc.)
- Fetches real tracks from Deezer’s public search API
- Returns:
  - Song title  
  - Artist  
  - Deezer track link  
  - 30‑second preview MP3  
- Zero authentication required  
- Perfect for frontend apps, demos, and portfolio projects
